

# 🟢 Estudo de Caso — Semáforo #

Este projeto apresenta um estudo de caso simples que simula o comportamento de um semáforo.
A partir da cor informada, o sistema exibe a instrução correspondente (por exemplo, "Verde" → "Siga em frente").

# 📌 Objetivo #

Demonstrar o uso de estruturas condicionais para interpretar o valor de uma variável (corSemaforo) e exibir a ação adequada ao usuário.

# Comportamento # 

Com base no valor da variável corSemaforo, o sistema deve exibir:
| Cor Informada    | Ação/Instruição    |
| ---------------- | ------------------ |
| `"Verde"`        | **Siga em frente** |
| `"Amarelo"`      | **Atenção**        |
| `"Vermelho"`     | **Pare**           |
| (Qualquer outra) | **Cor inválida**   |


# 📚 Aprendizados # 

Uso de condicionais (switch/case/default)

Lógica básica de tomada de decisão
